# ИНН КОМПАНИИ:Конкретный ИНН

## ТВОЯ ГЛАВНАЯ ЗАДАЧА

Проведи максимально глубокое исследование российской компании по указанному ИНН, установи её **действующее руководство**, изучи публичную информацию о компании и директоре, а затем подготовь **одно короткое, максимально персонализированное первое сообщение директору** по вопросу банковской гарантии.

### Главная цель сообщения:

**не продать банковскую гарантию.**

Цель первого касания:

**получить ответ директора → определить, кто занимается БГ → получить контакт ответственного → либо выйти на короткий разговор с самим директором.**

Сообщение должно выглядеть так, будто его написал человек, который **перед отправкой специально изучил именно эту компанию, её профиль деятельности и текущий бизнес-контекст.**

# КЛЮЧЕВОЙ ПРИНЦИП

## НЕ ИЩИ ПРОСТО ИНФОРМАЦИЮ. ИЩИ ПЕРСОНАЛЬНЫЕ БИЗНЕС-КРЮЧКИ.

Тебе не нужно собирать как можно больше фактов.

Тебе нужно понять:

**чем конкретно эта компания занимается сейчас, в каком бизнес-контексте находится и почему именно ей может быть естественно написать по вопросу банковских гарантий.**

Главный крючок должен быть связан **не с конкретным контрактом**, а с **самой деятельностью компании**.

В финальное первое сообщение конкретные контракты, закупки, номера процедур и конкретные заказчики **не выносятся**.

# ОТДЕЛЬНОЕ ПРАВИЛО ПО КЕЙСАМ

Если база реальных кейсов передана тебе в рамках задания, выбери из неё наиболее подходящий кейс именно под деятельность конкретной компании.

Кейс должен быть логически связан с компанией.

Не вставляй кейс просто ради наличия кейса.

Если подходящего подтверждённого кейса в доступных данных нет, **не создавай его самостоятельно**.

Не превращай предположение в реальный кейс.

* «в похожем случае мы сделали...»;
* «нашему клиенту оформили...»;

Можно делать аккуратный логический вывод из подтверждённых фактов, но не выдавать предположение за установленный факт.

# ЛОГИКА ПОДГОТОВКИ СООБЩЕНИЯ

Перед написанием сообщения для себя определи:

1. Кто действующий руководитель?
2. Чем реально занимается компания?
3. Какие направления являются наиболее существенными?
4. Какие устойчивые признаки деятельности компании можно использовать как персональный крючок?
5. Почему банковская гарантия логически связана именно с этим типом бизнеса?
6. Есть ли подтверждённый релевантный кейс в доступной базе?
7. Какую реальную ценность можно показать без выдумывания цифр и условий?
8. Какой один вопрос будет наиболее естественным следующим шагом?

После этого подготовь одно сообщение.

Эти промежуточные рассуждения не должны попадать внутрь блока готового сообщения.

# СТРУКТУРА ГОТОВОГО СООБЩЕНИЯ

Желательная логика:

**1. Короткое обращение к директору.**

**2. Персональный факт о компании.**

Используй название компании и конкретный подтверждённый бизнес-крючок.

**3. Логическая связь этого факта с банковскими гарантиями.**

Человек должен понимать, почему ему пишут именно по БГ.

**4. Ценность ДВК Финанс.**

Если есть подтверждённый релевантный кейс — используй его.

Если кейса нет — используй только подтверждённую общую ценность без выдуманных цифр и обещаний.

**5. Один понятный вопрос.**

Вопрос должен вести к ответственному за БГ или к короткому разговору.

Название компании и ДВК Финанс можно упоминать в основном тексте сообщения, когда это естественно связано с персонализацией и целью обращения. Запрет касается именно самовольного представления отправителя.

# КРИТИЧЕСКОЕ ТРЕБОВАНИЕ К ГОТОВОМУ СООБЩЕНИЮ

Когда в рамках выполнения этого задания ты подготовишь финальное

сообщение, которое должно быть использовано как готовое сообщение

клиенту, обязательно обрами ЕГО следующим образом:

ГОТОВОЕ СООБЩЕНИЕ

[здесь находится готовое сообщение]

КОНЕЦ СООБЩЕНИЯ

Важно:

1. Строка «ГОТОВОЕ СООБЩЕНИЕ» является только маркером начала.

2. Строка «КОНЕЦ СООБЩЕНИЯ» является только маркером конца.

3. Между этими двумя маркерами должен находиться полный текст

   готового сообщения.

4. Текст между маркерами должен быть именно тем сообщением,

   которое ты подготовил по этому заданию.

5. Не добавляй внутрь этих маркеров никаких пояснений,

   комментариев или вариантов.

6. Не создавай несколько блоков «ГОТОВОЕ СООБЩЕНИЕ».

7. Все остальные части твоего ответа находятся вне этих маркеров.

8. После строки «КОНЕЦ СООБЩЕНИЯ» не добавляй второй вариант сообщения,

   follow-up, дополнительные CTA или предложения по дальнейшему контакту.

9. Готовое сообщение между маркерами должно быть полностью

   самодостаточным и готовым к непосредственной отправке клиенту.
