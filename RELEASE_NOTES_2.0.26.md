# Telegram AI Sender 2.0.26

Добавлены отдельные архивы первой установки для Windows, macOS и Linux. Они включают полный код, публичную конфигурацию центра, первоначальную запись версии для будущих обновлений и PDF-инструкцию на русском со скриншотами.

Установщик проверяет существующий 64-разрядный Python 3.11–3.14. Если подходящего интерпретатора нет, Windows и Mac скачивают официальный Python 3.14.10 с закреплённой SHA-256 и проверкой подписи. На Linux используются системные пакеты поддерживаемых дистрибутивов; при необходимости на старой системе доступна сборка официальных исходников в пользовательскую папку. Системный Python не заменяется пользовательской сборкой. Установка системных компонентов Mac/Linux может потребовать пароль администратора.

Первая настройка выполняется в локальной странице браузера: номер менеджера, Telegram API ID/Hash, токен личного бота, ключ ИИ и при необходимости ключ судебного поиска. Настройки существующей установки не перезаписываются. Подключение к центру включено публичными параметрами; секреты владельца, личные сессии и базы в архивы не входят.

Инструкция объясняет создание бота через BotFather, получение токена, получение ключей у руководителя, авторизацию Telegram по QR-коду, ожидание доступа и последующие запуски с автоматической проверкой обновлений. Ни установка, ни тесты установщиков не запускают клиентскую рассылку.
