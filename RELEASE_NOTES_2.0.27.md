# Telegram AI Sender 2.0.27

При первой установке больше не требуется запрашивать и вводить Telegram API ID/Hash. Программа открывает технического бота центра: менеджер подтверждает свой аккаунт, руководитель разрешает доступ, и установка получает подписанные параметры в зашифрованном виде. Затем менеджер входит в тот же аккаунт по QR-коду.

Уже установленные версии, включая поддерживаемую 2.0.19, получают новый механизм через обычное обновление. Переход проверяет параметры приложения и прежний вход, сохраняет номер менеджера, сессию, базу и очередь. При недоступности центра прежние рабочие API-параметры сохраняются. Обычная проверка центрального доступа продолжает действовать.

API-параметров владельца нет в открытых установщиках и исходниках. Временный Google-посредник хранит только публичный запрос и зашифрованный ответ. На компьютере авторизованного менеджера параметры нужны программе для работы и остаются локальными настройками.

Обновлена русская PDF-инструкция со снимками новой формы. Установщики Windows, Mac и Linux автоматически подготавливают совместимый Python, если подходящей версии нет.

Проверки: шифрование и привязка к запросу/аккаунту, подписи центра и владельца, запрет выдачи без доступа, сохранение данных и откат при ошибке. Проверены оба транспорта через действующий центр и Telegram без сообщений клиентам. Проверки обновления и первой установки выполняются на Windows, Mac и Linux перед публикацией.
