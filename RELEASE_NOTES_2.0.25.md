# Telegram AI Sender 2.0.25

Исправлен продукт «Право_ИП»: исследование идентифицирует предпринимателя по 12-значному ИНН и сведениям ЕГРИП, без требований найти директора ООО. Судебные участники с префиксом «ИП» и без него сопоставляются при подтверждённом ИНН; поддержан ИНН ответчика, присутствующий только в подробной карточке. Совпадение одного ФИО не подтверждает дело. При отсутствии необходимых судебных фактов сохраняется ручная проверка.

Для «Право_ООО» и «Право_ИП» имя отправителя берётся из first_name профиля Telegram-аккаунта отправки. Фиксированное имя «Сергей» удалено. Фамилия и описание профиля в имя не включаются. Сохранённые ранее сообщения не переписываются и не отправляются повторно.

Также разрешён переход с существующим ненумерованным именем сессии без изменения номера менеджера. В центре внутреннее имя менеджера отображается рядом с ID в уведомлениях и списке пользователей при наличии заполненной карточки.

Проверки используют синтетические ответы судебного API и имитацию ИИ. Живая проверка проблемного ИНН ИП не выполнена: пример пока не предоставлен. Клиентские сообщения при проверке не отправлялись.
