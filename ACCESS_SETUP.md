# Подключение менеджера через подтверждение администратора

## Как работает доступ

1. Менеджер устанавливает программу и заполняет обязательные ключи в `.env`.
2. Менеджер запускает программу и открывает своего Telegram-бота.
3. Команда `/start` показывает инструкцию и Telegram ID менеджера.
4. Менеджер отправляет `/request_access`.
5. Администратор получает заявку в личном Telegram с кнопками **Разрешить** и **Отклонить**.
6. После разрешения ID автоматически добавляется в `data/allowed_users.json`. При отклонении доступ не открывается.

До подтверждения загрузка Excel, подготовка и отправка сообщений недоступны.

## Настройка администратора

В `.env` каждой менеджерской установки нужно заранее указать:

```env
ADMIN_TELEGRAM_ID=ЧИСЛОВОЙ_TELEGRAM_ID_АДМИНИСТРАТОРА
```

Это Telegram user ID аккаунта, который будет нажимать кнопки подтверждения. Не username и не ID бота.

**Владелец должен указать это значение до передачи установки менеджеру.** Если оставить поле пустым, заявки не будут отправляться.

## Первый контакт с каждым новым ботом

Telegram не разрешает боту первым написать пользователю. Поэтому администратор должен один раз открыть личный чат с конкретным менеджерским ботом и нажать **Start**. После этого бот сможет присылать этому администратору заявки.

Если заявка не доставлена, менеджер должен передать администратору ссылку/username своего бота. После нажатия **Start** менеджер отправляет `/request_access` повторно.

## Важное ограничение

Проверка подтверждения сравнивает Telegram ID нажавшего кнопку с `ADMIN_TELEGRAM_ID`. Это защищает обычный процесс одобрения от других пользователей бота. Поскольку программа устанавливается локально, администратор должен сам задавать это значение и не полагаться на него как на защиту от человека, который намеренно изменяет исходный код или конфигурацию программы.
