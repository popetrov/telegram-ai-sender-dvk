# Telegram AI Sender 2.0.28

У менеджеров исследование компаний выполняется последовательно: одновременно работает только одно исследование вместо десяти. Это снижает одновременную нагрузку на соединение при подготовке сообщений.

Для аккаунта владельца (Telegram ID 925600480) сохраняется лимит десять одновременных исследований. Исключение определяется по подключённому Telegram-аккаунту; номер менеджера и параметры конфигурации его не включают. До определения аккаунта применяется лимит один.

Бот показывает действующий лимит перед подготовкой. Исследования и сообщения сохраняются прежним способом; изменение не запускает отправку автоматически.

Проверки: фактическое число одновременно выполняющихся исследований для обычного аккаунта и владельца, сохранение всех результатов очереди, безопасный лимит при неопределённом аккаунте. Пакеты обновления и первой установки проходят проверки Windows, Mac и Linux перед публикацией.
