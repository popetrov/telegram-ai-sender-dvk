# Обновление с постоянной папкой

С версии2.0.40 данные, сессия и настройки остаются в основной папке. Код обновляется внутри скрытой .dvk/runtime; текущая и одна резервная версия кода. Возврат старой базы после запуска запрещён.

Каждый выпуск содержит полный пакет и полную последовательность миграций со всех поддерживаемых схем. Номер версии не ограничивает число пропущенных выпусков. Новую версию проверяет её собственный обновлятор; старый список модулей не препятствует установке новых. Промежуточные установки не требуются. Проверки совместимости старых установок сохраняются в переходном комплекте.

Прежние35/37/38/39 переходят через совместимый мост. Его кратковременная техническая папка скрыта и удаляется до запуска. Папки рабочих копий рядом больше не создаются. Используйте прежний файл запуска.

/installation показывает старые известные копии, безопасные для удаления после сохранения данных, и копии, которые нужно оставить. Несовпадающие базы никогда не объединяются автоматически. Активные или непроверенные процессы не дают разрешения на удаление папки.

Ручной переход: transition_setup.py --source ПАПКА --sender-stopped. Другая папка назначения не нужна. --prepare-only проверяет комплект, не меняя рабочую установку. Обычная установка и обновление не отправляют тестовые сообщения клиентам.

При сбое до первого рабочего запуска восстанавливается проверенный снимок. После рабочего запуска автоматический откат данных запрещён. Папка восстановления и маркер незавершённого перехода блокируют запуск смешанной установки.
