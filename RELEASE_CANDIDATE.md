# Статус: разработка, не выпуск для действующих пользователей

Эта ветка публикуется для проверки и совместной разработки. Не устанавливать
её поверх действующей программы и не публиковать как latest GitHub Release.
Версия в version.txt оставлена 2.0.19 для сохранения исходного состояния;
она не означает выпуск этих изменений под существующим тегом.

Добавлены бизнес-пакеты и адаптеры, черновик центрального доступа, общие оболочки
запуска Windows/macOS и подготовка отдельной копии для ручного обновления.
56 тестов прошли в Linux; dependencies и синтаксис проверены. Локальная репетиция
на базовом коммите 1b4e2fc с искусственными правками прошла.

Platform candidate checks запускает те же проверки и сборку development-артефакта
на Windows/macOS/Linux. Сами по себе добавление workflow и push не доказывают,
что эти проверки запустились или завершились успешно. Реальные проверки Telegram
и сохранности настоящих локальных данных пользователя не выполнялись.

Блокеры общего выпуска:

1. main.py требует настроенный центральный доступ. Центр @asdvk2026_bot ещё
   не развёрнут; существующим установкам не выданы проверенные разрешения.
2. Нет подписок компаний на календарный месяц + 2 дня, бесплатного режима ДВК
   и ограничения офлайн-разрешения окончанием подписки.
3. Нет синхронизации клиентских данных/анализов/сообщений исключительно владельцу.
4. Старый обновлятор не поддерживает новые модули и зависимости. Нужен совместимый
   переход с 2.0.19 и отдельный переход рабочей установки владельца с 2.0.9.
5. Нет подтверждённого полного сценария на обеих ОС, активации/проверки запуска
   и отката после миграций. manual_update.py только подготавливает отдельную копию.

Токены, ключи, Telegram-сессии и базы в публикацию не входят.
Исчерпывающий объём: PROJECT_REQUIREMENTS.md. Инструкции: BUSINESS_PACKAGES.md,
CENTRAL_ACCESS.md, MANUAL_UPDATES.md.
