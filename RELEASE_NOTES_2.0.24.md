# Telegram AI Sender 2.0.24

Исправлен переход с 2.0.20 и 2.0.21: подготовка обновления использует проверенные модули из нового переходного архива, а не устаревший список разрешённых файлов установленной версии. Контроль состава, SHA-256 и локальных изменений сохраняется.

Сохраняются настройки API, сессия, номер менеджера, база, очередь и отключённое автообщение. Для установок с прежним обновлятором обновлён однократный Windows-помощник.
