# 2.0.42 — запуск Windows без ошибок переходной папки и CMD

Исправлена WinError32 при первом запуске после обновления: переходная оболочка меняет рабочую папку до уборки. Занятость папки не прерывает запуск. Состав оболочки записан отдельно; незавершённая уборка повторяется при следующих запусках, без удаления пользовательских файлов. Пустые технические папки40/41 удаляются только операцией удаления пустого каталога в проверенном пространстве имён.

Существующий start.bat больше не заменяется, пока CMD может его выполнять. Путь к Python переключается отдельным ASCII-файлом на среду внутри основной папки; он не зависит от удаляемых старых копий и кодировки имени пользователя. Сохраняются исправление старых запускателей41, единая установка и пропуск промежуточных версий.

Клиентские базы, очереди, ограничения и диагностика удалений не меняются. Прерванная очередь не возобновляется автоматически. Центр и личная WORK не требуют перезапуска ради этого исправления менеджерского обновлятора.
