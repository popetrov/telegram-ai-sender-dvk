# 2.0.40 — единая установка и расследование исчезновения сообщений

Основой служит опубликованная 2.0.39. Статистика, Excel, учёт запросов ИИ и согласование форматов обмена сохранены. Личный ИИ-продавец владельца в общий пакет не входит.

Программа использует одну постоянную папку запуска и одну базу. Новые версии кода находятся в скрытой папке .dvk внутри неё; сохраняются текущая и одна предыдущая версия кода. Полный пакет и вся история миграций позволяют пропускать промежуточные выпуски: проверен прямой тест40→140 с новым модулем и100 миграциями. Будущие выпуски обязаны сохранять этот контракт совместимости.

Первый переход из прежних установок35/37/38/39 проверен настоящими обновляторами без Telegram. Их одноразовая оболочка совместимости удаляется до запуска. Старые известные копии того же аккаунта получают перенаправление в основную папку. Отличающиеся базы не смешиваются: сохраняются отдельно. Неизвестные файлы сохраняются перед отметкой «можно удалить». Работающий старый процесс или неполная проверка процессов запрещают такую отметку; принудительного завершения нет. Данные и расписание из устаревшей исходной папки не подменяют действующее состояние.

Добавлена цепочка метаданных: аккаунт/менеджер/база/процесс/ключ входа/версия → источник задания → запрос и ID целей → проверки SDK и сериализованной очереди → попытка записи в соединение → результат Telegram либо неизвестный исход → наблюдение исчезновения → подписанная квитанция центра. Ключи, пакеты сети и тексты переписки не выгружаются. Журнал сохраняется локально при недоступности центра; служебная доставка разрешена при защитной остановке только конкретному проверенному техническому сообщению. Отправки клиентам по-прежнему подчиняются действующим ограничениям; неизвестная доставка не повторяется автоматически.

В контроле переписки центра добавлен разбор удалений с сопоставленными операциями и пробелами наблюдения. Заблокированный запрос не считается выполненным удалением. Telegram не указывает автора удаления в личном чате, поэтому внешнего исполнителя нельзя определять только по времени события. Причина прежних реальных удалений этим выпуском ещё не доказана.

Не удаляйте старые папки по похожему названию. Раздел /installation показывает, какие проверены и какие пока требуется сохранить. Непроверенные копии на других устройствах остаются за пределами локальной проверки.
