# Установка Telegram AI Sender

Для первой установки на новый компьютер используйте архив для своей системы: `DVK_INSTALL_WINDOWS.zip`, `DVK_INSTALL_MACOS.zip` или `DVK_INSTALL_LINUX.zip`. Архивы находятся в стабильном выпуске: https://github.com/popetrov/telegram-ai-sender-dvk/releases/latest . Архив с названием `telegram_ai_sender_v...zip` предназначен для обновления старых установок, а не для первого запуска.

## Что получить у руководителя

- Ваш номер менеджера с ведущими нулями, например 010. Не придумывайте номер самостоятельно.
- Ключ ИИ. Его выдаёт владелец программы или руководитель вашей компании.
- Для ДВК Право — также ключ судебного поиска.

## Создать своего бота

1. В Telegram откройте https://t.me/BotFather — официальный аккаунт с отметкой проверки.
2. Нажмите «Запустить» и отправьте `/newbot`.
3. Введите название, например «Помощник Виктории».
4. Введите свободный username на латинице, заканчивающийся на `bot`, например `viktoria_dvk_010_bot`. Если имя занято, придумайте другое.
5. BotFather пришлёт токен — строку с цифрами, двоеточием и буквами. Скопируйте только эту строку.
6. Откройте ссылку на созданного бота и нажмите «Запустить». Сам бот начнёт отвечать после запуска программы на компьютере.

Токен — пароль управления вашим ботом. Не отправляйте его и ключи в общий чат или на снимках экрана. Официальная справка: https://core.telegram.org/bots/tutorial#obtain-your-bot-token .

## Windows

1. Скачайте `DVK_INSTALL_WINDOWS.zip`. Нажмите по архиву правой кнопкой → «Извлечь всё». Выберите отдельную постоянную папку, например `Документы\DVK Sender`. Запуск из открытого ZIP не подходит.
2. В распакованной папке дважды нажмите `install.bat`.
3. Дождитесь подготовки. Если подходящего 64-разрядного Python 3.11–3.14 нет, установщик скачает проверенный официальный Python. Вручную искать Python не нужно. Поддерживается 64-разрядная Windows 10/11; 32-разрядная Windows не поддерживается.
4. Появится страница «ДВК — первая настройка» в браузере. Заполните поля и нажмите «Сохранить и запустить».

## Mac

1. Скачайте `DVK_INSTALL_MACOS.zip` и распакуйте двойным нажатием. Перенесите папку в постоянное место, например «Документы».
2. Откройте `install_mac.command`.
3. Если Python отсутствует, программа скачает официальный подписанный пакет Python. В Терминале может потребоваться пароль администратора Mac. Символы пароля при вводе не отображаются — это нормально. Дождитесь окончания установки.
4. Заполните страницу первой настройки и нажмите «Сохранить и запустить».

Если macOS не разрешает открыть файл или у вас нет прав администратора, передайте руководителю снимок сообщения системы. Не отключайте защиту компьютера. Если файл открылся как текст, откройте Терминал, введите `bash ` с пробелом, перетащите `install_mac.command` в окно Терминала и нажмите Enter.

## Linux

Нужен Linux с графическим рабочим столом. Автоматическая установка системных компонентов поддерживает Ubuntu/Debian, Fedora и Arch. Для других дистрибутивов Python 3.11–3.14 с venv необходимо установить отдельно.

1. Скачайте и распакуйте `DVK_INSTALL_LINUX.zip` в постоянную папку.
2. Откройте Терминал в этой папке. Выполните `bash install_linux.sh`.
3. При запросе введите пароль администратора для установки Python и компонентов. Существующий подходящий Python используется повторно. На старой системе без подходящего Python установка из официальных исходников может занять заметно больше времени.
4. Заполните страницу первой настройки и нажмите «Сохранить и запустить».

## Первый вход в Telegram

1. После настройки программа откроет технического бота центра. Нажмите там «Запустить». Руководитель получит запрос и выдаст доступ. Параметры Telegram-приложения загрузятся автоматически в зашифрованном виде: API ID и API Hash запрашивать и вводить не требуется.
2. Вернитесь в окно программы: после разрешения центра появится QR-код. Войдите в тот же Telegram-аккаунт, которым подтвердили подключение.
3. На телефоне откройте Telegram → «Настройки» → «Устройства» → «Подключить устройство».
4. Сканируйте QR-код на своём компьютере. Если включён облачный пароль Telegram, введите его в программе. QR-код и пароль никому не пересылайте.
5. Оставьте программу запущенной. Откройте своего бота в Telegram и нажмите «Запустить».
6. Проверяйте состояние кнопкой «Доступ» или `/access`. Проверка центра выполняется периодически, поэтому подтверждение может появиться через несколько минут. Если время ожидания истекло, повторите обычный запуск — сохранённые поля вводить заново не нужно.

До разрешения центра отправка клиентам недоступна. Установка и авторизация сами по себе не запускают рассылку.

## Дальше каждый день

- Windows: открывайте прежний `start.bat`.
- Mac: открывайте `start_mac.command`.
- Linux: в прежней папке выполните `bash start_linux.sh`.

Проверка новых выпусков выполняется при запуске. Сохраняются вход, номер менеджера и локальная база. Переустанавливать программу для каждого обновления не нужно. Не переносите отдельные файлы программы между компьютерами и не удаляйте папки с базой или сессией.

Для работы с ботом используйте его кнопки. Отправка начинается только после подготовки списка и вашего подтверждения. Во время работы оставляйте компьютер включённым, с интернетом и без перехода в сон.

## Если что-то не получилось

Не удаляйте программу и не создавайте нового бота повторно. Пришлите руководителю название вашей системы, этап, на котором остановились, и снимок ошибки без токенов, ключей и QR-кода. Если программа не запускается, снимок окна установки важнее снимка переписки с ботом.
