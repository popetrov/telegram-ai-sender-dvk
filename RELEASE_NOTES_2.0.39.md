# 2.0.39 — статистика МОП и центра, учёт расходов ИИ

В ботах менеджеров добавлена кнопка «Статистика»: собственные отправки, входящие, подтверждённые прочтения и доступные данные за период, выгрузка Excel. Сбор входящих и прочтений не включает автоответы и не отправляет сообщения клиентам. Чужая статистика менеджеру недоступна.

В центре добавлена кнопка «Статистика»: все менеджеры, отдельный менеджер, организация и компания по центральным карточкам, периоды и выгрузка сводки. Используются только полученные от соответствующего аккаунта записи. Отсутствие новых данных и задержка синхронизации отмечаются отдельно.

Стоимость GPT-5 mini больше не пропускается из-за прежнего расчёта только GPT-4.1. Записываются использование первичного исследования, диалогов и Право, известные вызовы инструментов. Локальная оценка явно отделена от общих списаний ключа: отсутствующие запросы, другие модели, инструменты, история до обновления и запросы вне программы не выдаются за нулевой расход.

Для чтения фактических списаний организации OpenAI центр поддерживает отдельный Admin API key через локальную команду `center.bat billing-config`. Он не входит в пакеты менеджеров. Дневные данные провайдера имеют границы UTC и могут поступать с задержкой; они не объявляются точным расходом выбранного менеджера или суток Дубая.

Обновление центра необходимо до включения новых таблиц синхронизации. Их экспорт запускается только после подписанного подтверждения совместимости от центра. Прежние менеджеры продолжают обычный обмен. Статистика не снимает ограничения отправки и не возобновляет очередь.

Проверка стабильного релиза сначала использует ссылку GitHub без REST API: лимит запросов общего IP/VPN не блокирует этот путь. Проверка TLS, контрольные суммы и защита от установки предварительных релизов сохраняются.

Личные функции ИИ-продавца WORK владельца в общий выпуск не включены. Этап 4 требует пользовательской приёмки; этот выпуск не объявляет полный исторический учёт расходов восстановленным.
