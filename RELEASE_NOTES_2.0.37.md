# 2.0.37 — адресная остановка при исчезновении сообщения

Известное исчезнувшее сообщение блокирует только соответствующий диалог, включая повторную отправку после перезапуска. Остальные диалоги не останавливаются этим событием. Ранее записанные подтверждённые исчезновения применяются при обновлении; прежняя общая остановка по наблюдаемому удалению переводится в адресные запреты только при полной привязке всех сообщений. Журнал исходного инцидента сохраняется в архиве. Неопределённый чат, сбой обязательного контроля и запрещённые запросы самой программы сохраняют общую остановку. PeerFlood, opt-out и неясная доставка не обходятся.

Повторная проверка одного сообщения не создаёт вторую тревогу в центре; исторические отсутствия и разные сообщения показаны отдельно. Запросы технических ботов не учитываются как клиентская переписка. Причины предупреждений получают безопасный код исключения, если он был передан в лог.

Обновление не запрещает собеседнику Telegram удалить сообщения для обеих сторон и не объявляет виновника по одному событию. Доказательства сохраняются. Очередь не запускается автоматически. Личные функции WORK владельца в пакет не включены.

Дополнительно: при остановке защиты во время уже начавшейся отправки результат сохраняется как неопределённый, без автоматического повтора. Прямой запрет до подготовки по-прежнему не отправляет ничего. Релиз 2.0.36 удержан в черновике и заменён этим выпуском.
