# Telegram AI Sender 2.0.22

Исправлено получение автоматических обновлений при недоступности или ограничении GitHub API. Программа использует официальную страницу стабильного релиза, проверяет точный адрес и версию, затем скачивает полный переходный пакет с проверкой SHA-256. Пилотные релизы из ленты не используются. При повреждённом архиве, постороннем перенаправлении или ошибке сети продолжает работать прежняя установка.

Сохраняются настройки, в том числе недавно изменённая API-пара Telegram, существующая сессия, номер менеджера, база, очередь и состояние автообщения. Отключённое владельцем автообщение этим обновлением не включается.

Кнопки управления из 2.0.21 входят в обновление. Для уже установленных 2.0.20/2.0.21, которые не могут скачать обновление из-за ошибки GitHub API, подготовлено однократное исправление обновлятора. Оно определяет активную папку и сохраняет прежний файл для отката.

Этот выпуск не распространяет секретный профиль Telegram-приложения и не меняет API ID / API Hash остальных менеджеров автоматически. Отдельный закрытый пилот перехода проверяется независимо.
