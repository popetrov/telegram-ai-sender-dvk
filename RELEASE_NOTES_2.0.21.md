# Telegram AI Sender 2.0.21

В боте отправки появились постоянные кнопки: очередь, подготовка, отмена, доступ, диалоги, загрузка Excel и помощь. Снятие локальной остановки после спама требует отдельного подтверждения проверки аккаунта. Список диалогов можно листать кнопками.

В админ-боте центра добавлены кнопки менеджеров, компаний, выдачи и отзыва доступа, продления и карточки сотрудника. Для действий с параметрами бот запрашивает ID и компанию. Права доступа и неизменяемые номера менеджеров сохраняются.

Исправлен обмен с базой знаний для включённого владельцем режима автообщения: ответы привязаны к запросам в личном чате, цитаты выбираются по идентификаторам дословных отрывков. Временный сбой обмена не превращается в персональную ручную паузу каждого клиента. Переписки с удалёнными известными сообщениями исключаются из автоотправок.

Обновление само по себе не включает автообщение у других менеджеров: для него нужна отдельная настройка. Сохранённые очереди, .env, Telegram-сессии, номера менеджеров и локальные данные переносятся существующим механизмом обновления; автоматического возобновления прерванной первичной рассылки нет.

Для действующих установок обновление загружается при обычном запуске. Windows, macOS и Linux проверяются перед публикацией пакетов. Для старой замороженной Mac-ветки остаётся ранее подготовленный однократный переход.
