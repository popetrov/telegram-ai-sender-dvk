# Пилот центра: Windows CMD

Пакет требует установленного Python 3.11+ с pip и доступа в интернет для зависимостей
и Telegram. Это ZIP с установкой через CMD, не автономный EXE. Не обновляйте им
действующих менеджеров. Центр и отправитель распаковывайте в разные новые папки.
Рабочую C:\Users\Пользователь\Desktop\telegram_ai_sender_V2.0 не заменять.

## Установка центра

1. Распакуйте dvk-center-pilot.zip, например в C:\DVK\CenterPilot.
2. Откройте CMD и выполните:

```cmd
cd /d C:\DVK\CenterPilot
certutil -hashfile "C:\путь\dvk-center-pilot.zip" SHA256
center.bat check
center.bat install
center.bat run
```

Сравните SHA256 архива с опубликованным файлом .sha256 до установки. Установщик
создаст venv-center. Введите токен именно @asdvk2026_bot в локальном скрытом
вводе и свой числовой Telegram ID. Не вводите токен @baza_dvk_bot и не присылайте
токены в чат. Повторная установка сохраняет существующий .env.authority.

После подключения центр напечатает состояние и два публичных ключа. Они также
сохранены в data\access_authority\public_key.txt и sync_public_key.txt. Эти два
файла можно передать для настройки тестовой копии. signing.key, encryption.key,
.env.authority, базу и архивы резервных копий передавать нельзя.

Откройте @asdvk2026_bot своим административным аккаунтом, отправьте /start.
Служебный обмен удаляется отправителем из чата после проверки подтверждений.
Файлы и ответы могут кратко появляться во время передачи. При запуске отправитель
очищает служебные записи среди последних 2000 сообщений этого бота; обычные
сообщения, команды управления и ответы на них сохраняются. Данные SQLite не
удаляются. Очистка не должна мешать передаче данных при ошибке Telegram.
Держите консоль открытой, выключите сон компьютера. Ctrl+C останавливает центр.
Второй экземпляр центра в этой же папке не запустится. Два центра с одним токеном
в разных папках запускать нельзя: Telegram разрешает один polling-процесс.

## Команды владельца

```text
/users
/companies
/company buyer
/renew buyer
/approve 123456789 dvk
/approve 987654321 buyer
/revoke 123456789
/company_off buyer
```

dvk — единая бессрочная бесплатная компания ДВК Финанс/Право/Закупки; менеджера
можно отозвать. Прочие компании оплачиваются целиком: /renew добавляет календарный
месяц + 2 дня от действующего конца либо текущего времени для просроченного срока.
Конец месяца обрезается по последнему дню следующего месяца. Часовой пояс Asia/Dubai.
Создание/включение компании не продлевает оплату и не отменяет отзыв менеджеров.

## Подключение отдельной копии отправителя

Сначала остановите отправитель. Используйте новый пакет dvk-manager-pilot.zip
и его SHA256 для подготовки **новой** папки:

```cmd
python platform_updater.py stage --source "C:\Users\Пользователь\Desktop\telegram_ai_sender_V2.0" --package "C:\путь\dvk-manager-pilot.zip" --sha256 ХЭШ_ИЗ_ФАЙЛА --destination "C:\DVK\SenderPilot"
```

Команду выполняют из распакованного менеджерского пакета. Она проверяет архив,
готовит отдельную установку и переносит .env, SQLite, сессии, локальные продукты
и промпты. Сначала изучите update_report.json. Конфликты сохраняют локальный файл,
но требуют проверки. Химикаты для растений не включаются автоматически: черновой
файл сохраняется, отсутствующее в products.json определение не создаётся.
Для старых 2.0.9/2.0.19 без блокировки процесса требуется ручная остановка: новый
инструмент не может доказать остановку старого процесса, не использующего lock.

```cmd
cd /d C:\DVK\SenderPilot
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\activate.bat
python manager_setup.py
python main.py --self-check
python main.py
```

Настройка запросит только публичные ключи центра и сохранит MANAGER_ID существующей
базы. Личные ключи и токен рабочего бота остаются в локальном .env. После запроса
установки центр пришлёт владельцу реальный Telegram ID для /approve ID КОМПАНИЯ.
Управлять личным ботом может сам Telethon-аккаунт менеджера в личном чате; отдельное
локальное одобрение для него не требуется. Старая локальная схема сохраняется
только для совместимости до привязки Telegram-аккаунта.

Для обычного запуска сохраняется python main.py. start.bat по умолчанию запускает
без автоматических обновлений для пилота. Не используйте старый
launcher.py для этой тестовой копии. Готового автоматического переключения на
новую установку с проверкой сетевого запуска и откатом пока нет.

## Проверка пилота

Используйте тестовые клиентские данные и согласованный аккаунт получателя:

- одобрение, отзыв менеджера, отключение компании и окончание платного срока;
- выключение центра и перезапуск отправителя: срок 24 часа не продлевается;
- при истечении/отзыве следующая отправка и анализ блокируются, тексты остаются;
- очередь после перезапуска восстанавливается только по /queue с новым подтверждением;
  sending/uncertain автоматически повторять нельзя, сначала проверьте чат;
- выключите центр, подготовьте данные, включите центр и проверьте события SQLite;
  повтор доставки одного события не должен удваивать запись;
- убедитесь, что локальные продукты, промпты и сессия сохранились;
- проверьте остановку Ctrl+C и отсутствие повторного экземпляра.

Проверка каждые 5 минут не гарантирует мгновенный отзыв при сбое связи. Подписанный
доступ ограничен 24 часами и концом оплаты. Локальный код и часы не защищены от
умышленного изменения владельцем компьютера. --self-check проверяет только
импорты, миграцию локальной базы и каталог, а не настоящий сетевой запуск.

## Локальные копии и автозапуск (необязательно)

После выбора отдельной папки и согласования хранения, пример на 30 дней:

```cmd
center.bat backup-config --directory "C:\DVK\CenterBackups" --keep-days 30
center.bat autostart-on
```

Перезапустите центр. Раз в час он проверяет наличие сегодняшней UTC-копии,
создаёт одну в день при работающем центре, проверяет SQLite и архив и удаляет
свои копии старше выбранного срока только после успешного копирования.
Включение центра после пропущенных дней создаёт копию текущего дня.
Для отключения автозапуска: center.bat autostart-off.
Это автозапуск при входе в Windows с видимой консолью, не служба до входа.

Восстановление: остановите центр, распакуйте проверенную копию в **новую** папку
data\access_authority новой установки; сохраните исходную папку для отката.
Токен в архив не включён: восстановите .env.authority локально или настройте заново.
Сохраняйте оба закрытых ключа: их замена потребует перенастройки менеджеров.
